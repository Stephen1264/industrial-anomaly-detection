# 工业异常检测与定位

A 部分提供五类 MVTec AD 基准数据和小组自采的瓶子、螺母图像。仓库首页可查看加载和校验代码、固定划分和报告配图。

## 下载完整项目

1. 打开 [A 部分数据交接 Release](../../releases/tag/part-a-v1)。
2. 在 Assets 下载 `project-part-a.zip`，解压得到 `project` 文件夹。
3. 进入解压的目录，查看 [A 部分数据交接说明](<./A部分_数据交接说明.md>)，用里面的命令校验和加载数据。

完整包包含 1,674 张 MVTec AD 图像及 392 张官方掩码，以及 160 张自采图像和 24 张自采掩码。[报告数据小节](./report/data_section.md) 附有统计表和配图。
